## 1. 지도와 외부 연동이 앱에서 안 된다

매장을 눌러 들어가면 지도가 뜨지 않는다. 웹(GitHub Pages)에서는 되던 것이라,
앱으로 감싸면서 생긴 문제다.

### 원인 — 화면을 여는 주소가 다르다

앱은 화면을 **`https://localhost`** 에서 연다. Capacitor의 기본값이고
(`hostname = "localhost"`, `androidScheme = https`), `app/capacitor.config.ts`에
따로 지정한 것이 없어 그대로다.

카카오 JavaScript 키는 **개발자센터에 등록한 사이트 도메인에서만** 동작한다.
등록돼 있는 것은 `https://ceaser501.github.io`일 테고 `https://localhost`는 없다.
그래서 SDK 스크립트가 401로 떨어지고, `loadKakaoMap()`이 null을 돌려주고
(`client/src/utils/kakaoMap.js:26`), 화면은 지도 없이 정보만 보여준다.

### 할 일

- [ ] **카카오 개발자센터 → 내 애플리케이션 → 플랫폼 → Web → 사이트 도메인에
      `https://localhost` 추가.** 코드 수정 없이 이것만으로 될 가능성이 크다.
- [ ] 그래도 안 되면 `client/src/utils/kakaoMap.js`에서 실패 이유를 화면에 남기게
      한다. 지금은 조용히 null이라 무엇이 막혔는지 알 길이 없다.
- [ ] **T맵 길안내** — `client/src/utils/tmap.js:29`가 `window.location.href`에
      `intent://` 주소를 넣는다. Capacitor 웹뷰가 이 주소를 그대로 넘겨주는지
      확인이 필요하다. 안 되면 `@capacitor/app`의 `openUrl`이나 App 플러그인으로
      바꾼다.
- [ ] **주변 매장 검색**(`supabase/functions/search-places`)은 서버가 부르는
      REST라 도메인 제한과 무관하다. 지도가 살아난 뒤에 따로 확인한다.
- [ ] 확인 순서: 카카오 도메인 추가 → 지도 뜨는지 → T맵 → 매장 검색

## 2. 여러 장을 한 번에 등록하기

지금 `+`는 한 건씩만 받는다. 여러 장을 받아 바코드 번호가 같은 것끼리 묶고,
읽어낸 값을 확인시킨 뒤 한꺼번에 넣는다.

시안 네 가지를 그려뒀다 — <https://claude.ai/code/artifact/696cb219-748e-4d78-b610-58383057bbcb>

| | 전부 잘 읽힌 날 | 한 건 흐릴 때 | 기존 화면과 |
| --- | --- | --- | --- |
| A 묶음 띠 + 편집판 | 5번 눌러야 | 그 건만 고치면 끝 | 새 화면 |
| **B 카드 목록** | **1번** | 그 카드만 펼침 | **같음** |
| C 한 장씩 넘기기 | 5번 넘김 | 넘기다 만남 | 새 화면 |
| **D 빠진 것만 묻기** | **1번** | 그 칸만 물음 | **같음** |

**추천은 B를 뼈대로, 카드를 펼치면 A의 편집판, 등록 직전에 D의 질문이다.**
셋은 배타적이지 않다.

### 왜 B인가

- 전부 잘 읽힌 날에 손이 **한 번만** 간다. 카카오톡 원본은 거의 다 제대로 읽히니
  그게 대부분의 날이고, 그 경우를 빠르게 만드는 것이 여러 장을 한 번에 올리는 이유다.
- **아이폰에서는 이 화면이 유일한 다건 경로다.** 사진첩을 훑을 수 없기 때문이다
  (`client/src/utils/gallery.js`의 `isGalleryScanSupported` 참고). B로 가면
  안드로이드의 자동 찾기 결과와 아이폰의 직접 올리기가 똑같이 생긴 화면으로 모인다.
  배울 것도 만들 것도 하나가 된다.

### 이미 있는 것

묶는 규칙은 새로 만들 것이 없다. `client/src/utils/gallery.js`에 그대로 있다.

- 같은 바코드 번호면 한 건 (`seenCodes`)
- 원본(카카오톡·다운로드)이 있으면 캡처는 빼고 (`isOriginal`)
- 바코드가 사진 폭의 25%에 못 미치면 후보에서 제외 (`MIN_BARCODE_COVERAGE`)

### 할 일

- [ ] 시안 확정 (태수님)
- [ ] `+`에서 사진 여러 장 받기
- [ ] 받은 사진을 위 규칙으로 묶기 — 갤러리 훑기의 `collect()`에서 폴더를 읽는
      부분만 떼어내면 그대로 쓸 수 있다
- [ ] 묶은 결과를 확인시키는 화면 (확정한 시안대로)
- [ ] 일괄 등록 — `registerAll`과 미리 올려두기(`uploadGifticonImages`)를 그대로 쓴다
