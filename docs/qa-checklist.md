# 출시 전 전체 검수 목록

앱을 내보내기 전에 사람이 직접 한 번씩 해보는 것들. 자동 테스트가 못 잡는 것만 모았다 —
기기 권한, 실제 장소, 실제 사진, 서버 배포 같은 것들이다.

평소 개발 중에는 [docs/next.md](next.md)를 보고, **이 문서는 출시 직전에 처음부터 끝까지
한 번 훑는다.**

---

## 아직 한 번도 확인 못 한 것

여기 있는 것은 "안 될 것 같다"가 아니라 **"확인할 기회가 없었다"**는 뜻이다.

### 위치를 못 잡는 곳

지하철·지하주차장처럼 위치가 안 잡히는 데서 앱을 열어야 확인된다.

- [ ] 지하에서 앱 열기 → **"지금은 위치를 확인할 수 없어요. 지하나 실내에서는 안 잡힐 수 있어요."**
- [ ] 그 띠에 **X가 없어야** 한다 (닫으면 그날 하루 안 뜨는 규칙에 걸린다)
- [ ] 밖에 나와서 앱 다시 열기 → 저절로 사라지고 매장 안내로 바뀐다

### 위치 권한을 처음 묻는 자리

이미 권한을 준 기기에서는 안 보인다. **앱 데이터를 지우거나 새 계정**으로 들어가야 한다.

- [ ] 기프티콘이 있는 상태에서 앱 열기 → **"내 주변에서 쓸 수 있는 기프티콘을 알려드릴까요? [켜기]"**
- [ ] **누르기 전에는 시스템 권한 창이 안 떠야 한다** (무시해도 권한이 타지 않아야 한다)
- [ ] 켜기 → 시스템 창 → 허용 → 곧바로 매장 안내로 바뀐다
- [ ] 켜기 → 거절 → 그날은 다시 안 묻는다. 다음 날 다시 한 번 묻는다
- [ ] 기프티콘이 하나도 없으면 묻지 않는다

### 환영 인사

**새 계정으로 가입해야** 보인다(가입 7일 안).

- [ ] 가입하고 처음 들어오면 목록 위에 환영 띠
- [ ] X로 닫으면 사라진다
- [ ] 앱을 껐다 켜도 다시 안 뜬다 (띄운 순간 봤다고 적으므로)

### 아이폰

빌드 자체가 아직 없다.

- [ ] 여러 장 등록이 되는지 (아이폰에서는 이것이 유일한 다건 경로다)
- [ ] 사진첩 훑기 버튼이 안 보이는지 (지원하지 않는 것이 맞다)

## 서버 쪽 — 앱과 따로 배포해야 하는 것

앱을 새로 내도 이건 안 따라간다. 빠뜨리면 **화면은 멀쩡한데 기능만 죽는다.**

- [ ] `supabase/schema.sql` 실행 — 안 하면 공지가 종에 안 쌓인다(`notice_reads`)
- [ ] `supabase/purge-cron.sql` 실행 — 안 하면 "60일이 지난 알림은 자동으로 지워져요"가 거짓말이 된다
- [ ] `supabase functions deploy admin-stats` — 안 하면 관리자 페이지에서 **점검 중** 체크가 저장되지 않는다
- [ ] `supabase functions deploy delete-account` — 안 하면 계정 탈퇴가 막힌다
- [ ] `supabase/push-cron.sql` 실행 — 유효기한 임박 푸시
- [ ] `select jobname, schedule from cron.job;`으로 예약 세 개 확인

## 계정 탈퇴

되돌릴 수 없는 자리라 한 번은 실제로 해봐야 한다. **스토어 심사에서도 보는 항목이다.**

- [ ] 메모를 남긴 적 있는 계정으로 탈퇴 → 실제로 지워지는지
      (`gifticons.memo_by` 참조를 안 끊어서 막혔던 자리다. `supabase/schema.sql`을
      다시 돌려야 고쳐진다)
- [ ] 사진을 여러 번 올렸다 지웠다 한 계정으로 탈퇴 → 지워지는지
      (스토리지에 남은 파일의 '주인' 표시가 계정을 붙들던 자리다. 파일은 안 지우고
      주인 표시만 끊는다 — `supabase/schema.sql`의 `purge_my_data`)
- [ ] 그래도 막히면, 창에 뜬 문구에 **표.칸 이름과 건수**가 적혀 있다
      (`public.user_delete_blockers`가 붙들고 있는 자리를 이름으로 찍어준다.
      "storage.objects.owner 3건"처럼 나온다. 짐작하지 말고 그걸 보고 고친다)
- [ ] 탈퇴 뒤 같은 메일로 다시 가입 → 새 사람으로 들어오는지
- [ ] 혼자 있던 가족은 통째로 없어지는지
- [ ] 가족이 남아 있으면 내가 쓴 기록이 '탈퇴한 구성원'으로 남는지
- [ ] `supabase functions deploy delete-account` — 이 함수가 없으면 탈퇴가 통째로 막힌다

## 창이 다른 창으로 갈리는 자리

계정 삭제는 두 번 묻는다. 앱에서 창이 같은 자리에서 통째로 갈리는 곳은 여기뿐이고,
그 자리에서 뒤로가기 장치가 어긋나 두 번째 물음창이 뜨자마자 스스로 닫혔다. 탈퇴 버튼을
누를 기회가 없어서 서버로는 아무것도 나가지 않았다.

**이 종류는 jsdom 테스트로 안 잡힌다.** 테스트의 `.click()`은 진짜 pointerdown을 만들지
않아서, 겹친 창끼리 부딪히는 일이 아예 일어나지 않는다. 실제로 이 버그는 테스트를 다
통과한 채로 나갔다. 진짜 브라우저에서 눌러봐야 한다.

- [ ] 계정 삭제 → 계속 → **"정말 탈퇴할까요?"가 화면에 남아 있는지** (깜빡이고 사라지면 그 버그다)
- [ ] 탈퇴하기를 눌렀을 때 개발자도구 Network에 `delete-account` 줄이 생기는지
- [ ] 뒤로가기로 물음창을 닫으면 그 창만 닫히고 내 메뉴는 남는지
- [ ] 겹쳐 뜬 시트(가족 → 이름 바꾸기)에서 뒤로가기가 한 번에 하나씩 닫는지

## 미아 사진 청소 (관리자 화면)

되돌릴 수 없는 자리라 처음 몇 번은 지우기 전에 눈으로 본다. **잘못 남은 파일보다 멀쩡한
기프티콘의 사진이 사라지는 쪽이 훨씬 나쁘다.**

- [ ] `supabase/admin-stats.sql` 실행 + `supabase functions deploy admin-stats`
- [ ] 관리자 → **미아 사진** → 90일로 목록이 뜨는지
- [ ] 목록에 뜬 경로 한두 개를 **기프티콘 관리에서 검색**해 정말 안 쓰이는지 확인
- [ ] 방금 등록한 기프티콘의 사진이 목록에 **없는지** (나이 제한이 도는지)
- [ ] 몇 건 골라 지운 뒤 앱에서 목록·바코드가 멀쩡한지
- [ ] 지운 만큼 Supabase 스토리지 용량이 실제로 줄었는지

## 알아두면 헷갈리지 않는 것

검수하다 "버그인가?" 싶을 때 여기를 먼저 본다. **다 의도한 동작이다.**

- **관리자 로그인은 이제 시간으로 안 끊긴다.** 토큰 자체는 여전히 한 시간짜리지만
  (Supabase 기본값), 화면이 요청을 보내기 전에 5분 남았으면 미리 새로 받는다. 로그인
  화면으로 튕긴다면 그건 시간 때문이 아니라 진짜로 끊긴 것이다 — 아래 항목을 보자.
  여러 명이 쓰게 되거나 공용 PC에 두게 되면 `admin/index.html`의 `SESSION_MARGIN_MS`
  위 주석을 되살려 예전대로 되돌린다.
- **관리자 페이지와 웹 앱은 같은 로그인 기록을 쓴다.** 주소가 같은 도메인이라서다
  (`ceaser501.github.io`). 그래서 **브라우저에서 앱을 열어 로그아웃하면 관리자도 같이
  끊긴다.** 폰에 설치한 앱은 저장소가 따로라 상관없다.
- **종에는 가입한 뒤의 일만 쌓인다.** 새 계정으로 들어가면 목록이 비어 있는 게 정상이다.
  들어오기 전에 가족이 무엇을 했는지는 새로 온 사람의 소식이 아니다.
- **공지는 새 계정에도 다 보인다.** 그건 가족 단위가 아니라 앱 전체에 내는 것이라,
  게시 중인 공지는 언제 가입했든 보여야 한다. 가족 활동과 헷갈리지 않도록 확성기가 붙어
  있고 맨 위에 고정된다.
- **종 배지에 내 활동은 안 세어진다.** 방금 등록한 사람에게 "새 소식 1개"를 알리는 건
  이미 아는 일을 알리는 셈이다. 혼자 테스트하면 배지가 안 붙는 게 정상이고, **다른
  구성원 계정으로 등록·사용해야** 숫자가 붙는다. 목록에는 내 것도 그대로 나온다.
- **중요 공지 말풍선은 같은 공지로 하루에 한 번뿐이다.** 6초 뒤 사라진다. 다만 **새
  공지를 올리면 그날이라도 다시 한 번** 뜬다 — 그렇게 다시 보면 된다.
- **번호가 갈려도 아무 말도 안 한다.** 막대에서 읽은 값이 늘 기준이다.
- **다건에서 바코드 없는 사진은 버린다.** "몰라서 뺐어요" 한 줄만 뜬다.
