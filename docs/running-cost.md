## 한도를 예산에 맞춘다

**코드에 걸어둔 한도가 예산보다 두 배 크다.** 인식 2,000건 + 가격 600회를 다 채우면
114,000원이다. 하루 한도만 보고 정했던 값이라 달로 환산해보지 않았다.

| 환경변수 | 지금 | 바꿀 값 | 그 값이면 |
|---|---|---|---|
| `ANALYZE_TOTAL_MONTHLY_LIMIT` | 2,000 | **1,100** | 39,300원 |
| `PRICE_TOTAL_MONTHLY_LIMIT` | 600 | **80** | 5,800원 |
| | | 합 | **45,000원** (+Apple = 56,600원) |

```
supabase secrets set ANALYZE_TOTAL_MONTHLY_LIMIT=1100
supabase secrets set PRICE_TOTAL_MONTHLY_LIMIT=80
```

**Anthropic 콘솔의 월 한도는 $35로 잡는다.** 코드 한도가 다 차도 $32라 걸리지 않고,
코드에 구멍이 나면 거기서 멈춘다. 알림은 $20에 걸어둔다.

한도가 막히면 사용자에게 "오늘은 여기까지"가 뜬다. 막히기 시작하면 그건 사람이
늘었다는 뜻이고, 그때 예산을 다시 정하고 올린다. 미리 넉넉히 열어두지 않는다 —
요금은 열어둔 만큼 나간다.

## ⚠️ 다음 벽은 Supabase다

기프티콘 한 건이 **124KB**를 쓴다(원본·바코드 크롭·썸네일 합쳐서. 94개 파일 4.6MB를
37건으로 나눈 실측이다). 무료 티어 1GB에 **약 8,400건**이 담긴다.

월 1,100건이면 **8개월 뒤 찬다.** 그다음은 Pro $25 = 월 35,000원이고, 그러면 예산이
한 번에 깨진다. AI 요금보다 이쪽이 먼저 문제가 된다.

미리 할 일은 없다. 다만 그때가 오면 고를 수 있는 것은 세 가지다.

- **쓴 기프티콘의 원본 사진을 지운다.** 바코드 크롭과 썸네일만 남기면 한 건이
  40KB 아래로 내려간다 — 무료 티어가 세 배 길어진다
- 보관 화질을 더 낮춘다
- Pro로 올린다 (100GB까지 열린다)

첫 번째가 제일 싸고, 쓴 기프티콘의 원본을 다시 볼 일이 없다는 점에서 잃는 것도 없다.
