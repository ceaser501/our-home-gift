## 한도를 예산에 맞춘다

**코드에 걸어둔 한도가 예산보다 크다.** 인식 2,000건이면 71,400원이고 Apple까지
83,000원이다. 하루 한도를 보고 정한 값이라 달로 환산해보지 않았다.

| 환경변수 | 지금 | 바꿀 값 | 그 값이면 |
|---|---|---|---|
| `ANALYZE_TOTAL_MONTHLY_LIMIT` | 2,000 | **1,200** | 42,900원 |
| `PRICE_TOTAL_MONTHLY_LIMIT` | 600 | **80** | 실제로는 0원 (버튼이 꺼져 있다) |
| | | 합 | **42,900원** (+Apple = 54,400원) |

```
supabase secrets set ANALYZE_TOTAL_MONTHLY_LIMIT=1200
supabase secrets set PRICE_TOTAL_MONTHLY_LIMIT=80
```

**Anthropic 콘솔의 월 한도는 $35로 잡는다.** 코드 한도를 다 채워도 인식 $31 +
가격검색 backstop $4 = $35라 정상 사용으로는 걸리지 않고, 코드에 구멍이 나면 거기서
멈춘다. 알림은 $20에 걸어둔다.

한도가 막히면 사용자에게 "오늘은 여기까지"가 뜬다. 막히기 시작하면 그건 사람이
늘었다는 뜻이고, 그때 예산을 다시 정하고 올린다. 미리 넉넉히 열어두지 않는다 —
요금은 열어둔 만큼 나간다.

첫 번째가 제일 싸고, 쓴 기프티콘의 원본을 다시 볼 일이 없다는 점에서 잃는 것도 없다.
