# 모아콘 사용 안내(브로셔)

홍보용으로 쓰는 사용자 매뉴얼입니다. 앱 화면 24장을 순서대로 따라가면서
로그인부터 계정 삭제까지 무엇을 어떻게 하는지 보여줍니다.

| 파일 | 쓰임 |
| --- | --- |
| `docs/manual/index.html` | 웹 브로셔. 브라우저로 바로 열면 됩니다. |
| `docs/manual/moacon-manual.pdf` | 같은 내용을 A4 13쪽으로 뽑은 것. 인쇄·전달용. |
| `docs/manual/shots/` | 브로셔에 쓰인 앱 화면 사진 |

## 고칠 때

글과 배치는 `docs/manual/index.html` 한 파일에 다 들어 있습니다. 사진을 바꾸려면
`docs/manual/shots/`에 같은 이름으로 덮어쓰면 됩니다(가로 700px 기준).

PDF는 이 HTML을 크롬으로 인쇄해서 만듭니다. 인쇄용 배치는 파일 맨 아래
`@media print` 블록에 따로 잡혀 있어요.
