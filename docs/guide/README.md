# 모아콘 사용 안내 (새 브로셔)

`docs/manual/`(먼저 만든 것)은 참고용으로 그대로 두고, 여기서 새로 씁니다.

| 파일 | 쓰임 |
| --- | --- |
| `docs/guide/guide.src.html` | **고치는 파일.** 글·배치·장 목록이 다 여기 있습니다. |
| `docs/guide/shots/` | 화면 사진. 가로 600px, JPEG 품질 82로 줄여 넣습니다. |
| `docs/guide/build.py` | src에 sho­ts/를 박아 넣어 `guide.html`을 만듭니다. |
| `docs/guide/guide.html` | **띄우는 파일.** 손으로 고치지 않습니다 — 돌릴 때마다 덮어써집니다. |

## 왜 둘로 나눠 두었나

브로셔는 웹으로 띄우는데, 거기서는 바깥 주소로 그림을 못 불러옵니다. 그림이 파일 안에
통째로 들어가 있어야 해요. 그런데 9장까지 가면 화면이 마흔 장 가까이 되고, 그만큼의
긴 문자열이 박힌 파일은 열어서 고칠 수가 없습니다. 그래서 **고치는 파일과 띄우는
파일을 나눕니다.**

```
python3 docs/guide/build.py
```

## 고치는 법

장은 `guide.src.html` 아래쪽 `CHAPTERS` 배열에서 나옵니다. 장 하나가 객체 하나예요.

- `state: 'wait'` → 차례에 "캡처 대기"로 뜨고, 아래에 `need`(보내주실 화면)가 붙습니다
- `state: 'done'` → "작성됨"으로 바뀌고 `body`에 넣은 내용이 나옵니다

즉 **차례만 봐도 어디까지 왔는지, 다음에 무엇을 찍어야 하는지** 알 수 있습니다.

## 화면 사진 넣기

1. 받은 캡처를 `shots/이름.jpg`로 줄여 넣습니다 (가로 600px)
2. src에서 `<img src="shots/이름.jpg" alt="...">`로 가리킵니다 — 경로는 `shots/`로 시작해야
   build.py가 알아봅니다
3. `python3 docs/guide/build.py`

한 장에 딸려 오는 빈 여백이 많으면(알림처럼 화면 위 한 줄이 전부인 경우) 카드를 잘라낸
비율로 두고 `object-position`으로 보여줄 자리를 잡습니다. 표지의 세 장이 그 예입니다.

## 쓸 때 지키는 것

- 읽는 사람이 20대부터 아버지 세대까지입니다. **본문 18px**, 한 항목은 **제목 한 줄 + 설명 두 줄까지**
- 기능 이름 말고 하는 일로 씁니다 — "찜 기능"(X) → "내가 쓸게요 표시"(O)
- 화면에 적힌 글자는 `<span class="ui">사용완료</span>`처럼 그대로 인용합니다
- **실명을 넣지 않습니다.** 가족은 `우리 가족`, 사람은 `아빠 / 엄마 / 아들 / 딸`
  (목데이터의 받은 사람도 이 넷으로 맞춰뒀습니다 — `client/src/sampleData.js`)
- **브랜드 로고는 쓰지 않습니다.** 상호는 화면 안의 글자로만 나오고, 맨 아래 고지문으로
  제휴가 아님을 밝힙니다

## 자리잡은 모양 (계속 지킬 것)

- **번호는 차례가 있을 때만.** 1장의 로그인 네 걸음처럼 순서대로 해야 하는 것에만 번호를
  붙입니다. 0장의 세 가지처럼 나란한 이야기에는 붙이지 않습니다
- **꼭 짚어야 할 것은 `.warn` 상자로.** 연보라 바탕만 쓰고 왼쪽에 굵은 선은 두지 않습니다.
  상자 안의 `.ui` 인용 칩만 바탕을 흰색으로 뒤집습니다(바탕색이 같아 칩이 안 보이므로)
- **화면 사진은 붙이기 전에 확인합니다.** 브라우저가 서로 다르면 `최근 로그인` 같은 표시가
  다른 자리에 붙어 나옵니다. 나란히 놓을 두 장은 같은 조건에서 찍은 것만 씁니다

## 이어서 할 일

차례에 `캡처 대기`로 뜬 장이 남은 일입니다. 그 장의 `need`에 어떤 화면이 필요한지 적혀
있습니다. 사진을 받으면 `shots/`에 넣고 `state: 'done'`으로 바꾼 뒤 `body`를 씁니다.

한 가지 미리 걸린 것 — **`엄마` 계정을 가족에 넣으면 `shots/list.jpg`를 다시 찍어야
합니다.** 이름표 색이 가족에 실제로 있는 사람이면 그 사람 색을 쓰기 때문에(자리:
`client/src/components/GifticonCard.jsx`, 순번: `supabase/schema.sql:119`), 엄마가
구성원이 되는 순간 청록에서 분홍으로 바뀝니다. 이미 넣어둔 표지 사진과 어긋납니다.
