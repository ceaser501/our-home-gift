## 보는 곳

웹으로 올려두고 고칠 때마다 같은 주소에 덮어씁니다. 태수님은 새로고침만 하면 최신을 봅니다.

## 고치는 법

장은 파일 아래쪽 `CHAPTERS` 배열에서 나옵니다. 장 하나가 객체 하나예요.

- `state: 'wait'` → 차례에 "캡처 대기"로 뜨고, 아래에 `need`(보내주실 화면)가 붙습니다
- `state: 'done'` → "작성됨"으로 바뀌고 `body`에 넣은 내용이 나옵니다

즉 **차례만 봐도 어디까지 왔는지, 다음에 무엇을 찍어야 하는지** 알 수 있습니다.

## 화면 사진

이 파일은 웹에 올릴 때 바깥 파일을 못 불러옵니다. 사진은 `data:` 로 파일 안에 넣습니다
(가로 700px, JPEG 품질 80 정도로 줄여서 넣습니다).

## 쓸 때 지키는 것

- 읽는 사람이 20대부터 아버지 세대까지입니다. **본문 18px**, 한 항목은 **제목 한 줄 + 설명 두 줄까지**
- 기능 이름 말고 하는 일로 씁니다 — "찜 기능"(X) → "내가 쓸게요 표시"(O)
- 화면에 적힌 글자는 `<span class="ui">사용완료</span>`처럼 그대로 인용합니다
- **실명을 넣지 않습니다.** 가족은 `우리 가족`, 사람은 `아빠 / 엄마 / 아들 / 딸`
  (목데이터의 받은 사람도 이 넷으로 맞춰뒀습니다 — `client/src/sampleData.js`)
