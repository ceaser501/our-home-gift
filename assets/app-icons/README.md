# 앱 아이콘 원본

스토어 제출과 네이티브 빌드에 쓰는 아이콘이다. 웹에서 실제로 서빙되는 파일은
여기가 아니라 `client/public/` 아래에 있다.

| 파일 | 크기 | 쓰는 곳 |
| --- | --- | --- |
| `icon-1024.png` | 1024×1024 | iOS App Store Connect 제출용 |
| `play-store-512.png` | 512×512 | Google Play 스토어 등록 정보 |
| `android-adaptive-foreground.png` | 432×432 | 안드로이드 어댑티브 아이콘 전경 (투명 배경) |
| `android-adaptive-background.png` | 432×432 | 안드로이드 어댑티브 아이콘 배경 |

## 제출할 때 주의할 점

- **iOS는 알파 채널을 거부한다.** `icon-1024.png`는 이미 불투명하게 뽑아뒀으니 다시 저장하면서
  투명도가 끼어들지 않게 한다.
- **모서리를 직접 굴리지 않는다.** iOS와 안드로이드가 알아서 깎는다. 파일에 라운딩이 들어가 있으면
  두 번 깎여서 가장자리가 지저분해진다.
- **어댑티브 아이콘은 전경/배경을 따로 넣는다.** 한 장으로 합쳐 넣으면 기기가 원형·물방울 등
  제조사 마스크를 씌울 때 상자 옆면이 잘린다. 전경은 안전원(지름 66/108) 안에 들어가도록
  이미 축소해 뒀다.

## 다시 만들려면

도형 원본은 `client/public/icon.svg`(벡터)다. 그레인은 `mix-blend-mode`에 의존해서
지원하지 않는 렌더러에서 회색 막으로 떨어지기 때문에 벡터 원본에는 넣지 않고
PNG로 구울 때만 얹는다. 그래서 `icon.svg`를 그대로 리사이즈하면 그레인이 빠진 결과가 나온다.
