# 앱 아이콘

모아콘 마크는 **밝은 보라 → 진한 보라 그라데이션 위에 9도 기울인 MOA 워드마크**다.
그림은 없다. 홈 화면에서 눈에 걸리게 하는 건 세 가지뿐이다 — 글자를 꽉 채우고,
다른 앱에 없는 보라를 쓰고, 혼자 삐딱하게 서 있는 것.

```
#8B5CF6 → #3A2F96   배경 그라데이션 (135°)
#FFD84D             가운데 O 고리
#FFFFFF             M · A
9도                 기울기 (반시계)
```

## 어디를 고쳐야 하나

**원본은 `assets/brand/` 아래 SVG 다.** 여기 PNG 는 전부 거기서 구워낸 사본이고,
`client/public/`·`admin/`·`app/android/…/res/` 로 다시 복사된다.
색이나 크기를 바꾸려면 SVG 를 고치고 전부 다시 구워야 한다.

글자는 폰트 이름이 아니라 **패스로 박아 뒀다**(Nunito 1000 에서 뽑음).
Nunito 가 없는 기계에서 열어도 똑같이 그려진다.

```
assets/
├─ brand/       ★ 원본 SVG. 여기가 진짜다
├─ app-icons/
│  ├─ store/    앱스토어·플레이스토어 제출용 (알파 채널 없음)
│  ├─ android/  적응형 아이콘 레이어
│  ├─ web/      client/public/ 에 들어간 것과 같은 파일
│  ├─ sizes/    낱개 크기. 문서·외부 서비스 등록용
│  └─ admin/    관리자 대시보드용
├─ splash/      앱 진입 화면
└─ marketing/   스토어 배너·공유 썸네일
```

## 투명 규칙이 자리마다 반대다

| 파일 | 투명 | 이유 |
|---|---|---|
| `store/icon-1024.png` | **금지** | 알파 채널이 있기만 해도 App Store 업로드가 거부된다 (`ITMS-90717`) |
| `store/play-store-512.png` | 없음 | Play 는 허용하지만 마스크와 그림자를 씌우므로 꽉 채운 쪽이 안전 |
| `android/…-foreground.png` | **필수** | 배경 레이어 위에 얹히는 층이다 |
| `web/icon-*.png` | 있음 | 모서리가 둥근 그림이라 바깥이 비어야 한다 |

`store/` 아래 두 장은 RGB(알파 없음)로 저장돼 있다. 다시 구울 때 이 점을 놓치면
심사가 아니라 **업로드**에서 막힌다.

## 안드로이드 적응형은 크기 계산이 따로다

레이어는 108dp 인데 런처가 보여주는 건 가운데 **72dp(66.7%)** 뿐이다.
그래서 `icon-adaptive-foreground.svg` 는 그림을 미리 66.7% 로 줄여 그려 놓았고,
`mipmap-anydpi-v26/ic_launcher.xml` 에는 **인셋을 걸지 않는다.**

예전에는 여기에 16.7% 인셋이 걸려 있었다. 그림도 줄이고 인셋도 걸어서 로고가
두 번 작아졌고, 그게 런처에서 아이콘이 작아 보이던 원인이었다.

## 앱과 관리자는 아이콘이 다르다

같은 MOA 글자를 쓰지만 관리자는 **그라데이션 없이 진한 남보라 단색**이고
아래에 금색 지표 막대가 들어간다. 홈 화면에 둘이 나란히 있어도 헷갈리지 않아야 한다.

## 다시 구우려면

`assets/brand/` 의 SVG 를 고친 뒤, 그 SVG 를 각 크기로 래스터해서 위 경로에 덮어쓴다.
`store/` 두 장은 알파를 떼고 RGB 로 저장한다.
