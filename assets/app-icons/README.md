# 앱 아이콘 원본

아이콘 전체 사이즈를 한곳에 모아뒀다. 스토어에 올리거나 외부 서비스에 등록할 때
여기서 꺼내 쓰면 된다.

웹에서 **실제로 서빙되는 파일은 여기가 아니라 `client/public/` 아래**다.
`web/` 안의 것과 같은 파일이지만, 배포되는 쪽을 고칠 때는 `client/public/`을 고쳐야 한다.

```
assets/app-icons/
├─ web/       client/public/ 에 들어가 있는 것과 같은 파일 (사본)
├─ store/     앱스토어·플레이스토어 제출용
├─ android/   안드로이드 어댑티브 아이콘 레이어
├─ sizes/     낱개 사이즈. 문서·발표자료·외부 서비스 등록용
└─ admin/     관리자 대시보드용 (딥 퍼플). 서빙되는 파일은 admin/ 아래에 있다
```

## 앱과 관리자는 아이콘이 다르다

같은 상자·뚜껑·하트를 쓰지만 관리자는 **몸통에 지표 막대가 들어가고 딥 퍼플**로 눌렀다.
둘 다 홈 화면에 설치했을 때 어느 쪽이 관리자인지 알아볼 수 있어야 하기 때문이다.
도형 좌표는 앱과 픽셀 단위로 같으니, 상자 모양을 고칠 일이 생기면 양쪽을 함께 고쳐야 한다.

| 파일 | 크기 | 쓰는 곳 |
| --- | --- | --- |
| `web/icon.svg` | 벡터 | 원본. 크기 무관 |
| `web/favicon.ico` | 16·32·48 묶음 | 브라우저 탭 |
| `web/icon.png` | 180×180 | apple-touch-icon |
| `web/icon-192.png` | 192×192 | PWA 설치 아이콘 |
| `web/icon-512.png` | 512×512 | PWA 스플래시 |
| `web/icon-maskable-512.png` | 512×512 | 안드로이드 크롬이 원형·물방울로 깎을 때 |
| `store/icon-1024.png` | 1024×1024 | iOS App Store Connect |
| `store/play-store-512.png` | 512×512 | Google Play 등록 정보 |
| `android/android-adaptive-foreground.png` | 432×432 | 어댑티브 전경 (투명 배경) |
| `android/android-adaptive-background.png` | 432×432 | 어댑티브 배경 |
| `sizes/icon-{16,32,48,64,128,256}.png` | 각 크기 | 낱개 |

## 제출할 때 주의할 점

- **iOS는 알파 채널을 거부한다.** `store/icon-1024.png`는 이미 불투명하게 뽑아뒀으니
  다시 저장하면서 투명도가 끼어들지 않게 한다.
- **모서리를 직접 굴리지 않는다.** iOS와 안드로이드가 알아서 깎는다. 파일에 라운딩이
  들어가 있으면 두 번 깎여서 가장자리가 지저분해진다.
- **어댑티브 아이콘은 전경/배경을 따로 넣는다.** 한 장으로 합쳐 넣으면 제조사 마스크를
  씌울 때 상자 옆면이 잘린다. 전경은 안전원(지름 66/108) 안에 들어가도록 이미 축소해 뒀다.

## 만드는 규칙

- **그레인은 PNG에만 있다.** `mix-blend-mode`로 얹는 효과라 이를 지원하지 않는 렌더러에서는
  불투명한 회색 막으로 떨어진다. 어디서 열려도 똑같이 보여야 하는 벡터 원본에는 넣지 않았다.
  그래서 `icon.svg`를 그대로 리사이즈하면 그레인이 빠진 결과가 나온다.
- **16·32px은 다른 그림이다.** 리본 절개폭이 1px 아래로 내려가면 회색 얼룩으로만 남고
  하트도 뚜껑에 붙어 뭉갠다. 그래서 이 두 크기는 리본과 핑크 틴트를 빼고 도형을 키운
  단순화 버전으로 따로 그렸다.

## 아이콘을 또 바꾸게 되면

`client/public/`과 `client/src/components/Logo.jsx`를 같이 고쳐야 하고,
`client/index.html`과 `client/public/manifest.json`의 `?v=` 숫자를 올려야 한다.
안 올리면 이미 방문한 브라우저와 설치된 PWA가 예전 아이콘을 계속 들고 있는다.
